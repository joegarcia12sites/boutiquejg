# BOUTIQUE JG — JENNIFER GARCIA

Loja virtual de alta moda feminina com Painel Administrativo (CMS) integrado.

## 🚀 Como publicar na Vercel via GitHub

1. Suba os arquivos `index.html` e `vercel.json` na raiz do seu repositório no **GitHub**.
2. Acesse [vercel.com](https://vercel.com), clique em **Add New... → Project** e importe o repositório.
3. Em **Framework Preset**, mantenha **Other** (não requer comando de build).
4. Clique em **Deploy**.

## 🔒 Acesso ao Painel Administrativo
- Clique no botão **Admin** ou use o atalho de teclado `Ctrl + Shift + A` (ou acesse `/?admin=1`).
